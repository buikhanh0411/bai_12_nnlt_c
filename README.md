# Quản lý sinh viên
Tạo một app console yêu cầu nhập xuất và đi kèm các tiện ích

### Compile code
<ul>
  <li>
      <b>CMake (Khuyên dùng):</b>
      <pre><code>mkdir -p build && cd build
cmake ..
make
./student_manager</code></pre>
  </li>
  <li>
      <b>GCC (Nhanh):</b>
      <pre><code>gcc *.c -o student_manager
./student_manager</code></pre>
  </li>
</ul>
